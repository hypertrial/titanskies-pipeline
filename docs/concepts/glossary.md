# Glossary

| Term | Meaning |
| --- | --- |
| Granule | One TEMPO NetCDF product instance tracked in the inventory ledger |
| `canonical_region_id` | Stable administrative region key from the geography contract |
| `is_analysis_ready` | Row meets the scope quality-policy thresholds |
| NRT scope | `tempo:no2` near-real-time TEMPO NO₂ L3 product |
| Standard scope | `tempo:no2_std` TEMPO NO₂ L3 V04 product |
| Overlap weights | Pinned area weights mapping native cells to regions |
| Grid latest | Public mart retaining only the latest supported-country cell observation |
| Contract CSV | Single quality-policy seed per scope (`tempo_no2*_contract.csv`) |
